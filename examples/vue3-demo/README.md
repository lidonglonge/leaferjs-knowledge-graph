# Vue3 + Element Plus 演示项目

LeaferJS 知识图谱插件的 Vue3 演示项目

## 快速开始

```bash
# 进入项目目录
cd examples/vue3-demo

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 功能演示

- ✅ 基础图展示
- ✅ 三种布局切换（力导向/环形/网格）
- ✅ 节点/边操作
- ✅ 数据导入导出
- ✅ 主题切换

## 技术栈

- Vue 3 + TypeScript
- Element Plus
- LeaferJS + leaferjs-knowledge-graph
